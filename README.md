# 打字练习程序

一个功能完整的打字练习程序，帮助用户快速熟悉键盘布局并提升打字效率。

## 功能特点

### 1. 练习模式
- **键盘熟悉**：分区域练习（左手区、右手区、全部字母区、数字区、符号区）
- **打字练习**：三级难度（初级、中级、高级），实时统计速度和准确率
- **自定义练习**：支持用户输入任意文本进行练习

### 2. 游戏模式
- **键位下落消消乐**：字符从屏幕上方掉落，按对应键位消除
- **限时打字挑战**：1分钟或3分钟限时挑战，测试打字速度
- **错误键位特训**：针对用户经常出错的键位进行强化练习

### 3. 数据统计
- 实时计算打字速度（WPM）和准确率（%）
- 记录练习历史和游戏最高分
- 统计错误键位频次，提供针对性训练

### 4. 设置功能
- 字体大小调节（小、中、大）
- 主题切换（浅色、深色）
- 音效开关
- 数据管理（清空记录）

## 技术栈

- **React 18 + TypeScript**：类型安全的前端开发
- **Vite**：快速的开发构建工具
- **localStorage**：本地数据存储
- **CSS3**：响应式布局和动画效果

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:5173/` 启动

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist/` 目录

## 使用说明

### 练习模式
1. 选择练习区域（左手区、右手区、全部字母区、数字区、符号区）
2. 按屏幕高亮的键位进行练习
3. 练习过程中会显示正确和错误次数
4. 完成10次正确输入后结束练习

### 打字练习
1. 选择难度（初级、中级、高级）
2. 开始输入屏幕显示的文本
3. 实时显示打字速度和准确率
4. 完成输入后显示练习报告

### 自定义练习
1. 输入你想要练习的任意文本
2. 点击开始练习
3. 程序会自动提取字符供你练习

### 游戏模式
1. **键位下落消消乐**：按对应键位消除掉落的字符，防止落地
2. **限时挑战**：在规定时间内尽可能准确地输入文本
3. **错误键位特训**：专门练习你经常出错的键位

## 数据存储

所有数据都保存在浏览器的 `localStorage` 中，包括：
- 练习记录（最近10次）
- 游戏最高分
- 错误键位统计
- 用户设置

## 开发说明

### 添加新的单词库

在 `src/constants.ts` 中的 `WORD_LISTS` 对象添加新的单词列表：

```typescript
export const WORD_LISTS = {
  beginner: [...],
  intermediate: [...],
  advanced: [...],
  // 添加新难度
  expert: [...]
};
```

### 自定义练习文本

在 `src/constants.ts` 中的 `PRACTICE_TEXT` 对象添加新的练习文本：

```typescript
export const PRACTICE_TEXT = {
  beginner: '...',
  intermediate: '...',
  advanced: '...',
  // 添加新难度
  expert: '...'
};
```
